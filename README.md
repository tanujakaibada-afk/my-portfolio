# Kaibada Tanuja - Personal Portfolio Website

A modern, clean, and responsive single-page personal portfolio website built for **Kaibada Tanuja**, an Artificial Intelligence & Data Science graduate.

---

## 🌟 Features

* **Hero Section:** Introduction, profile picture display, and resume download link.
* **About Me:** Brief overview of technical background and passion for coding.
* **Skills Showcase:** Grid display highlighting Programming languages, Web Development, and Database Management.
* **Projects:** Detailed cards for key projects:
  * **Portfolio Website:** Responsive personal website using HTML, CSS, and JavaScript.
  * **AI Medical Assistant:** An AI-powered tool to help users analyze symptoms and provide preliminary health guidance.
* **Contact & Socials:** Direct links for Email, Phone, and LinkedIn profile.
* **Animations:** Interactive scroll-triggered fade-in animations using JavaScript (`IntersectionObserver`).
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.

---

## 🛠️ Tech Stack

* **HTML5:** Web page structure
* **CSS3:** Custom styles, Flexbox, CSS Grid, linear gradients, and smooth scrolling
* **JavaScript (ES6+):** Intersection Observer API for scroll animations
